# Curate Professional UI

Instruksi:
- Mulai dari tugas pengguna dan hierarki informasi.
- Cari referensi 21st.dev hanya untuk komponen yang dibutuhkan.
- Periksa lisensi, dependensi, versi Tailwind, serta SSR compatibility.
- Jangan menginstal satu template penuh hanya untuk mengambil satu tombol.
- Jangan mengirim secrets atau data pelanggan ke layanan katalog.
- Gunakan katalog komponen, bukan generator AI tambahan.
- Adaptasi warna, ukuran, teks, dan interaksi ke sistem desain AutoDocs.
- Uji tampilan mobile dan keyboard.
- Hormati reduced motion.
